# Reality Check — AI Content Authenticity Analyzer

A web application that analyzes images and determines whether they are AI-generated or real, with a confidence percentage and plain-language explanation.

🔗 **Live site:** https://reality-check-rxqu.onrender.com

---

## Features

- Instant AI vs real image detection
- Confidence percentage score
- Plain-language explanation of results
- Clean, dark UI optimized for trust and clarity

## Tech Stack

- **Backend:** Python, Flask
- **Detection Engine:** Sightengine AI API
- **Frontend:** HTML, CSS
- **Deployment:** Render

## Run locally

```bash
git clone https://github.com/Aylin-Urumi/ai-content-detector.git
cd ai-content-detector
pip install -r requirements.txt
export SIGHTENGINE_USER=your_user
export SIGHTENGINE_SECRET=your_secret
python3 app.py
```
